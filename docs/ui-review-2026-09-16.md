# NeoCanvas interface review

Reviewed current shared Compose code and previously supplied screenshots. No new interactive visual inspection was performed.

## Implemented in this pass

- Replace seeded decorative layer thumbnails with actual raster content, fitted to document aspect ratio over a transparency checkerboard. Hidden layers retain a useful preview.
- Scroll the layer cards independently while keeping layer actions at the bottom.
- Constrain layer names so long names cannot push the visibility control out of the card.
- Replace manual toolbar offsets and calculated canvas width with measured Column/Row layout. Toolbar and status messages reserve their own space instead of overlapping the canvas.
- Keep the inspector beside the canvas on wide windows; place it below the canvas on narrow windows instead of covering the drawing surface.
- Increase toolbar and symmetry targets to 48 dp, retaining active-tool highlighting and exposing selected semantics.
- Add hover/long-press tooltips to icon and symmetry controls using the shared Material tooltip component.
- Add previous/more-tool arrows when the main toolbar overflows. Each arrow scrolls the existing toolbar and disables at its respective end; touch scrolling remains available.
- Group New/Open/Import/Save/Export into a labelled File menu, freeing the scrolling area for drawing tools.
- Keep Undo and Redo outside the scrolling toolbar so history controls remain visible.
- In compact windows, consolidate inspector navigation into a Studio menu with explicit Layers, Brushes, Colour and Hide panel actions. Wide windows retain individual inspector buttons.

## Still to address

- Interactive verification of tooltip gestures and toolbar overflow on Windows and Android tablets.
- Direct manipulation handles for image scale and rotation.
- Interactive checks at tablet portrait/landscape and Windows display-scaling settings, including pointer alignment after zoom and pan.
- Layer previews are cached at tile level, but very large layers would benefit from dedicated downsampled preview caching.

## Verification

Desktop UI tests, including pixel assertions for layer preview placement/transparency and layer isolation; Android UI compilation and Windows host compilation passed. Visual layout and input behavior still need an interactive check.
