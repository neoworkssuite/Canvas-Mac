# Changelog

## 1.0.0 — release candidate

- Establish the iPad implementation as the NeoCanvas product reference.
- Preserve and begin consolidating macOS, Windows, and Android platform work.
- Add one product-version contract while retaining native build numbers.

This version is a release candidate, not a declaration that every platform has
reached parity. See `docs/PLATFORM-PARITY.md` for evidence-based status.
